# Portfolio material rules

## GitHub description

Production-style Indian Railways delay analytics platform using Python, Snowflake, dbt,
data-quality controls, time-safe baseline evaluation, and React dashboard contracts.

## Claims permitted today

- Repository architecture, data contracts, ingestion validation, dbt/Snowflake definitions,
  audit design, tests, baseline code, and dashboard shell are implemented.
- The project does not yet claim a live Snowflake run, external-source ingestion, dashboard
  metrics, or trained-model performance.

## Claims permitted after validated execution

Use measured values only for row counts, source coverage, dbt tests, model metrics,
pipeline runtime, and dashboard screenshots.
